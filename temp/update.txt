  New Features

  1. Keywords Management
  - New keywords table in DB — add/remove/enable/disable individual keywords from the dashboard
  - Keywords automatically migrated from old settings string on startup

  2. Resume Upload
  - Auto-scheduled twice daily at configurable times (09:00,18:00 by default)
  - Manual trigger button on dashboard
  - "Resume last updated on" widget
  - Resume file: RomeshJain_10March_Resume.pdf (configurable in Settings)

  3. Daily Apply Limit
  - Configurable from Settings (default: 10/day)
  - When limit reached → jobs go to Manual Review Queue instead of being skipped

  4. Manual Review Queue
  - New dashboard section showing jobs discovered after daily limit
  - Per-job: Auto Apply (easy apply) or Open Job (external apply) + Skip
  - Separate from the main jobs table

  5. Telegram Notifications (node-telegram-bot-api)
  - Sends notification per job with Apply / Skip inline buttons
  - Handles Apply All / Skip All bulk actions
  - Toggle: approval required vs auto-apply mode
  - Fully configurable from Settings (token, chat ID, enable/disable)

  6. Dashboard (7 sections)
  - Dashboard — stats cards (Total/Applied/Today/Pending/Manual Review), resume/profile timestamps, quick action buttons
  - Jobs — filtered table with Easy Apply badge, status badges, per-job Auto Apply / Open / Skip
  - Manual Review — dedicated queue management
  - Keywords — add, enable/disable, delete keywords
  - Logs — filterable by level, shows job/event context
  - History — bot run history
  - Settings — all configuration without code changes

  7. Manual Controls (dashboard buttons)
  - Run Bot — full run with apply
  - Scrape Jobs — discover only, all go to Manual Review
  - Refresh Profile — bumps Naukri last-active timestamp
  - Upload Resume — manual resume upload
